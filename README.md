## 🚀 Quickstart

TotallyLegitFirewall.ai deploys via our revolutionary **Zero-Infrastructure Delivery Model™**, also known as "it's one HTML file."

### Option 1: Open it

Double-click `index.html`. You now have Enterprise-Grade Cyber Defense. Congratulations.

### Option 2: Serve it like a professional

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` and assume the role of CISO.

### Option 3: Deploy to production (please don't)

Upload `index.html` to any static host — GitHub Pages, Netlify, S3, a USB drive someone found in a parking lot — and it will run identically, because there is no backend to misconfigure. This is the single most secure architectural decision in this repository.

**Is this a real firewall product?**
No. It is a satirical browser game about the gap between how hacking looks in movies and how security incidents actually happen (a phishing email, a USB drive, and the intern).

**Is HACK BACK™ legal?**
No. Please do not hack anyone. This button hacks nobody. It just looks extremely cool.
